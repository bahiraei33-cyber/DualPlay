# DualPlay — نمونه اولیه

این پروژه یک نمونه اولیه WPF برای Windows 11 است، با دو تب مینیمال:
- **Dual Play**: دریافت صدای خروجی پیش‌فرض ویندوز با WASAPI loopback و کپی آن به خروجی دوم.
- **Reverse Play**: فعلاً بررسی/نمایش محدودیت گیرنده صدای بلوتوث؛ پیاده‌سازی کامل A2DP Sink در این نسخه وجود ندارد.

## پیش‌نیازها
- Windows 11
- .NET 8 SDK
- Visual Studio 2022 با workload مربوط به .NET desktop development
- دو هدفون/دستگاه صوتی متصل و قابل مشاهده در Windows Sound

## اجرا
1. فایل `DualPlay.csproj` را در Visual Studio باز کنید.
2. Restore NuGet packages را اجرا کنید.
3. پروژه را Build و اجرا کنید.

یا از ترمینال در پوشه پروژه:
```powershell
dotnet restore
dotnet run
```

## محدودیت‌های مهم نسخه اولیه
1. فهرست دستگاه‌ها فعلاً از خروجی‌های صوتی فعال ویندوز گرفته می‌شود، نه تمام دستگاه‌های Pair شده اما قطع. دستگاه باید به‌صورت خروجی صوتی فعال در ویندوز دیده شود.
2. در نسخه اول، هدفون اول باید از قبل خروجی پیش‌فرض ویندوز باشد. برنامه صدای آن را با loopback می‌گیرد و به هدفون دوم می‌فرستد.
3. پخش روی هدفون دوم ممکن است به‌دلیل تفاوت فرمت‌های صوتی، درایور یا محدودیت بلوتوث خطا بدهد؛ این نسخه هنوز تبدیل فرمت پیشرفته و جبران خودکار تأخیر ندارد.
4. Reverse Play از طریق Bluetooth نیازمند پشتیبانی A2DP Sink در ویندوز/درایور یا یک گیرنده سازگار است. این پروژه درایور نصب نمی‌کند و دریافت صدای گوشی را هنوز پیاده‌سازی نکرده است.

این پروژه کد منبع نمونه اولیه است؛ فایل اجرایی کامپایل‌شده همراه آن نیست.
